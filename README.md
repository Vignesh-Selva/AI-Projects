# AI Projects

A curated collection of analytics, machine learning, NLP and RAG applications built using Python, Jupyter Notebook, OpenAI APIs and public datasets.
The projects showcase work across EDA, visualization, predictive modeling, deep learning and LLM-based solutions.

---

## Projects Included

### 1. Combat Hate Speech on Twitter

A complete NLP pipeline to classify toxic tweets.
Includes:

* Text preprocessing (stopwords, tokenization, normalization)
* TF-IDF vectorization
* Classical ML models: Logistic Regression, SVM
* Deep dive into accuracy, precision, recall and F1-score
* Visualization of toxicity distributions and insights

---

### 2. Creating Designs (RAG + OpenAI)

Generates Netflix-style thumbnails using OpenAI models.
Includes:

* RAG-based prompt enhancement
* Context-aware creative content generation
* Automated design creation workflow

---

### 3. HR Chatbot (RAG + OpenAI)

A context-aware HR chatbot using Retrieval Augmented Generation.
Features:

* Chunked document embeddings
* Vector search for context retrieval
* OpenAI model integration
* Structured responses to HR queries

---

### 4. Lending Club Loan Data Analysis

Exploratory and deep learning–based analysis of loan default risk.
Includes:

* Data cleaning, feature engineering
* Exploratory visual analysis (loan amounts, terms, grades, purposes)
* Deep Learning model with TensorFlow/Keras
* Train/test evaluation with accuracy tracking
* Insights on borrowing patterns and risk indicators

---

### 5. Sales Analysis

Business-focused EDA on sales datasets.
Includes:

* Cleaning and preprocessing
* Monthly and yearly sales trends
* Regional and product-wise performance
* Visualizations with Matplotlib and Seaborn
* Actionable business insights

---

### 6. Employee Turnover Analytics

Predictive modeling to understand and forecast employee churn.
Includes:

* EDA on salary, distance, job roles, and attrition
* Label encoding and preprocessing
* ML model (e.g., Random Forest / Logistic Regression depending on notebook content)
* Performance metrics: accuracy, confusion matrix, classification report
* Insights on key factors influencing attrition
